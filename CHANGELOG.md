# Changelog

All notable changes to this extension are documented here. The format
is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## [1.0.16] - 2026-10-06

### Added
- New Show On Pages setting (General Settings) chooses the page types where notifications may appear: product pages, category pages, home page, search results and CMS pages. The default is product pages only.

### Changed
- Notifications never appear on the cart, checkout, order success or customer account pages, whatever is selected, so they no longer cover cart totals, checkout buttons or account forms.
